# 仿雷电（1990）安卓版 —— 详细 UI 设计规范

> 本文档提供可直接落地的像素风 UI 设计方案，包含具体尺寸、配色值、布局参数、动画规格，开发者/美术可直接按此执行。
>
> 当前状态说明：项目已采用 Unity 2D 运行时 UI 实现。本文的像素风规范仍作为美术方向参考；实际落地以 `MenuBootstrap`、`UIController`、`UiFactory`、`ArcadeTheme` 和 `RuntimeSpriteFactory` 为准。下方新增“当前 Unity UI 落地状态”用于同步真实界面。

## 一、整体视觉风格定义

### 1.1 设计语言
- **风格**：16-bit 街机像素风，硬边、高对比、无渐变（纯色块）
- **氛围**：军事科技感 + 复古霓虹，严肃中带电子酷炫
- **边框**：所有 UI 面板必须有 2px 深色描边（#0A0A0A）+ 1px 内发光高光边
- **字体**：等宽像素字体（Press Start 2P / 同类中文像素字体），强制无抗锯齿

### 1.2 核心配色板
```
主色调：
├── 背景黑：    #080810（比纯黑更有层次）
├── 面板底：    #1A1A2E（深蓝黑）
├── 军事绿：    #00FF41（P1 战机主色/确认按钮）
├── 电子蓝：    #00D4FF（P2 战机主色/激光主题）
├── 警示红：    #FF0040（危险/取消/Boss警报）
├── 能量黄：    #FFD700（高分/道具/高亮）
├── 纯白色：    #FFFFFF（标题/重要文字）
└── 暗灰色：    #4A4A6A（次要文字/禁用状态）
```

### 1.3 像素网格规范
- **基准像素**：所有 UI 元素按 8px 网格对齐
- **最小可点击区域**：48 x 48 px（安卓 Material Design 手指友好标准）
- **屏幕参考尺寸**：以 1080 x 1920（竖屏）为设计基准，向下适配
- **安全区域**：距离屏幕边缘 24px，避开系统状态栏/导航栏

## 二、字体规范（像素等宽字体）

### 2.1 字号层级
| 层级 | 字号 | 用途 | 颜色 | 描边 |
|------|------|------|------|------|
| 超大标题 | 32px | 游戏Logo、关卡大标题 | #FFFFFF | 2px #0A0A0A |
| 大标题 | 24px | 界面标题、Boss名称 | #00D4FF 或 #FFD700 | 2px #0A0A0A |
| 正文 | 16px | 菜单选项、说明文字 | #FFFFFF | 1px #0A0A0A |
| 小字 | 12px | 版本号、版权信息 | #4A4A6A | 无 |
| 分数数字 | 20px | 实时分数、高分榜数字 | #FFD700 | 1px #0A0A0A |
| 警示文字 | 20px | 警告、游戏结束 | #FF0040 | 2px #FFFFFF（红底白边） |

### 2.2 字体渲染要求
- **必须使用位图字体**：TTF 字体需关闭抗锯齿渲染
- **中文适配**：若用中文字体，每个字 16x16 像素位图，保持硬边
- **数字字体**：分数数字建议使用 LCD/数码管风格像素字体

## 三、各界面详细设计

### 3.1 启动/Logo 画面（2秒）

```
屏幕：1080 x 1920
背景：纯色 #080810

元素：
├── 中央 Logo 图
│   ├── 尺寸：400 x 200 px
│   ├── 内容：像素风 "RAIDEN" 大字 + 闪电图标
│   ├── 颜色：主色 #00D4FF，描边 #FF0040（1px）
│   └── 动画：从上方 100px 外落入，耗时 0.5s，弹性缓冲
│
├── 底部版权文字
│   ├── 文字："© 1990 SEIBU KAIHATSU / TRIBUTE VERSION"
│   ├── 字体：12px
│   ├── 颜色：#4A4A6A
│   └── 位置：屏幕底部居中，距底边 60px
│
└── 整体流程：
    ├── 0.0s：黑屏
    ├── 0.2s：Logo 开始下落
    ├── 0.7s：Logo 落定，闪一下（亮度 100%→150%→100%，0.1s）
    ├── 1.0s：版权文字渐显（Alpha 0→1，0.3s）
    └── 2.0s：自动切换到标题画面
```


## 六、多分辨率适配方案

### 6.1 设计基准与缩放
```
设计基准：1080 x 1920（竖屏，16:9）
缩放策略：
├── 高分辨率（1440p+）：UI 保持 1080p 尺寸，居中显示，边缘留空
├── 全面屏/刘海屏：顶部避开安全区域 48px，底部避开 60px

└── 平板横屏：强制竖屏显示（Android screenOrientation="portrait"）
```

### 6.2 像素完美渲染
- Bitmap 资源按 1x / 2x / 3x 提供（hdpi / xhdpi / xxhdpi）
- Canvas 绘制时关闭抗锯齿：
```kotlin
paint.isAntiAlias = false
paint.isFilterBitmap = false
paint.isDither = false
```
- 所有坐标取整：避免亚像素渲染导致的模糊

### 8.3 像素字体渲染工具类
```kotlin
class BitmapFontRenderer(
    private val fontAtlas: Bitmap,  // 包含所有字符的精灵图
    private val charWidth: Int = 16,
    private val charHeight: Int = 16
) {
    private val charMap = mapOf(
        '0' to 0, '1' to 1, '2' to 2, // ... 数字、字母映射到精灵图索引
        'A' to 10, 'B' to 11, // ...
    )

    fun drawText(
        canvas: Canvas,
        text: String,
        x: Float,
        y: Float,
        paint: Paint = Paint()
    ) {
        var offsetX = x
        for (char in text) {
            val index = charMap[char] ?: continue
            val srcRect = Rect(
                index * charWidth, 0,
                (index + 1) * charWidth, charHeight
            )
            val dstRect = RectF(
                offsetX, y,
                offsetX + charWidth, y + charHeight
            )
            canvas.drawBitmap(fontAtlas, srcRect, dstRect, paint)
            offsetX += charWidth
        }
    }
}
```

### 8.4 9-patch 风格面板绘制（不使用 Android 9-patch，自定义绘制确保像素完美）
```kotlin
fun drawPixelPanel(
    canvas: Canvas,
    x: Float, y: Float,
    width: Float, height: Float,
    borderColor: Int = Color.parseColor("#00D4FF"),
    fillColor: Int = Color.parseColor("#1A1A2E"),
    borderWidth: Float = 2f
) {
    // 填充背景
    val fillPaint = Paint().apply {
        color = fillColor
        style = Paint.Style.FILL
    }
    canvas.drawRect(x, y, x + width, y + height, fillPaint)

    // 绘制边框（像素直角，无圆角）
    val borderPaint = Paint().apply {
        color = borderColor
        style = Paint.Style.STROKE
        strokeWidth = borderWidth
        isAntiAlias = false  // 关键：关闭抗锯齿
    }
    canvas.drawRect(
        x + borderWidth / 2, y + borderWidth / 2,
        x + width - borderWidth / 2, y + height - borderWidth / 2,
        borderPaint
    )

    // 四角装饰（可选）
    drawCornerDecor(canvas, x, y, borderColor)  // 左上
    drawCornerDecor(canvas, x + width - 8, y, borderColor)  // 右上
    drawCornerDecor(canvas, x, y + height - 8, borderColor)  // 左下
    drawCornerDecor(canvas, x + width - 8, y + height - 8, borderColor)  // 右下
}
```
