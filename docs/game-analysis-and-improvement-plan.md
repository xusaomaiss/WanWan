### 1.2 当前核心短板

1. **视觉表现停留在"功能级"**：爆炸、受击、UI 切换等缺少"爽快感"和"街机感"
2. **战斗交互维度单一**：玩家只需"躲+射"，缺少高风险高回报的操作空间
3. **敌机行为模板化**：5 种编队循环，玩家容易形成固定走位套路
4. **武器差异停留在数值**：4 种武器主要是弹幕形状不同，缺少场景策略性
5. **无对象池**：每发子弹、每个敌机都 `new GameObject()`，GC 压力大
6. **长期目标不足**：8 关循环后只有难度提升，缺少成就收集和自我挑战机制

## 二、界面美化优化方案

### 2.1 UI 动画与过渡系统

**现状**：菜单、HUD、结算全是瞬间切换或简单显隐，缺少流畅感。

**改进方向**：

| 场景 | 当前表现 | 目标表现 |
|------|----------|----------|
| 标题页按钮 | 直接显示 | 从底部依次弹入（间隔 0.1s），带弹性缓动 |
| 战机选择卡片 | 静态排列 | 选中卡片放大 1.05x + 霓虹边框呼吸灯；未选中卡片半透明 |
| 难度选择 | 静态卡片 | 悬停/选中时卡片上浮 8px + 边框流光扫描 |
| 结算页面 | 直接显示全部文字 | 分数从 0 滚动递增（1.5s），统计项依次淡入 |
| 暂停菜单 | 直接覆盖 | 背景模糊（或暗化）+ 弹窗缩放进入 |
| Boss 警报 | 文字直接弹出 | 屏幕边缘红色警示条闪烁 + Boss 剪影从上方滑入 + 心跳音效 |

**技术实现建议**：
- 在 `UIController` 中增加 `CanvasGroup` 动画协程封装
- 使用 `DOTween` 或手写 `Vector3.Lerp` + `Ease Out Back` 缓动函数
- 结算页分数滚动使用 `Mathf.Lerp` 插值 + 每帧更新 Text

**炸弹清屏升级**：
1. 触碰瞬间：**时间缩放降至 0.2**（持续 0.2s）

3. 从炸弹位置扩散**3 层同心冲击波**（蓝→白→透明）
4. 敌机和子弹被清除时逐个延迟爆炸（0.02s 间隔的连锁反应）
5. 恢复正常时间流速，屏幕微震 0.2s

## 三、游戏可玩性深度优化

### 3.1 核心机制：擦弹（Graze）系统

**设计目的**：增加高风险高回报的操作空间，提升弹幕游戏的"刀尖跳舞"快感。

**机制说明**：
- 当敌方子弹进入战机**擦弹判定圈**（比命中判定大 2~3 倍）但未真正命中时，触发擦弹
- 连续擦弹积累**"专注槽"**（Focus Gauge）
- 专注槽满时自动触发**"超频模式"**（持续 5 秒）：
  - 射速提升 30%
  - 金币自动吸附范围翻倍
  - 战机周围产生蓝色能量场（视觉效果）

**UI 表现**：
- 专注槽显示在战机下方（细条能量槽）
- 擦弹时显示极小字号的 `"擦!"` 飘字（白色，向上淡出）
- 超频激活时屏幕边缘泛蓝光 + 战机拖影效果

### 3.2 武器系统策略深化

**当前问题**：4 种武器差异主要是弹幕形状，没有明显的"场景优势"。

**改进方案：属性克制系统**

| 武器 | 基础特性 | 场景优势 | 劣势 |
|------|----------|----------|------|
| 扇形弹 | 散射覆盖面广 | 对**集群小型敌机**效率最高 | 单体伤害低，对装甲目标乏力 |
| 激光弹 | 高速贯穿 | 对**地面装甲目标**（坦克/炮台）1.5x 伤害 | 无法覆盖侧翼 |
| 追踪弹 | 自动锁定 | 对**高速机动目标**（精英机）命中率优势 | 伤害较低，可被障碍物阻挡 |
| 爆裂弹 | 命中爆炸 | 对**密集编队**有溅射加成 | 射速慢，对单体浪费 |

**UI 提示**：
- 当玩家面对某类敌人时，若当前武器是劣势武器，HUD 武器图标轻微闪烁提醒
- 优势武器命中时，伤害数字显示为**金色**

### 3.3 模块组合效果（Synergy）

**当前问题**：模块是简单叠加，缺少"1+1>2"的惊喜感。

**组合效果表**：

| 组合 | 效果名称 | 具体表现 |
|------|----------|----------|
| Pierce + Wave | 扩散贯穿 | 贯穿弹命中后向两侧分裂出小弹 |
| Homing + RapidFire | 集束追踪 | 追踪弹射速提升，且锁定时间缩短 |
| Guard + Pierce | 堡垒模式 | 侧翼护卫弹也获得贯穿效果 |
| RapidFire + Wave | 波动弹幕 | 射出的弹幕呈波浪形扩散，覆盖更大区域 |

**触发反馈**：首次触发组合效果时，屏幕中央显示 `"Synergy! 组合激活"` 大字提示，持续 1.5 秒。

### 3.4 敌人 AI 与行为多样化

**新敌机类型**：

| 类型 | 外观 | 行为 | 应对策略 |
|------|------|------|----------|
| 自爆机 | 红色、闪烁灯光 | 血量低时加速冲向玩家，碰撞即爆 | 优先远处击落，不可靠近 |
| 护盾机 | 前方有蓝色力场 | 正面免疫伤害，必须从侧后方攻击 | 绕后或使用追踪弹 |
| 维修机 | 绿色、无武装 | 不攻击，每 3 秒给周围敌机回复 1 HP | 优先击杀，否则敌机越打越多 |
| 弹幕机 | 大型、悬浮 | 移动到屏幕中上部后停驻，发射扇形弹幕 | 利用弹幕间隙靠近输出 |
| 诱饵机 | 携带假火力包 | 被击落后掉落红色假包，触碰扣血 | 观察颜色（假包偏暗红闪烁） |

**地面目标扩展**：
- **地对空导弹车**：锁定玩家 1.5 秒后发射高速追踪导弹（可被玩家子弹拦截）
- **雷达站**：不攻击，但存在时所有敌机射速提升 30%
- **运输车队**：一长串缓慢移动的目标，全摧毁后奖励额外金币

### 3.5 Boss 战阶段机制升级

**现状**：Boss 主要靠弹幕密度变化，机制较单一。

**改进：多阶段机制变化**

以第 3 关 "海峡拦截舰" 为例：

| 血量阶段 | 机制变化 | 玩家应对 |
|----------|----------|----------|
| 100%~70% | 标准弹幕：扇形散射 + 直线核心弹 | 常规躲避 |
| 70%（转阶段）| 两侧炮塔展开，场地两侧出现纵向激光封锁 | 只能在中间狭窄区域活动 |
| 70%~40% | 召唤护卫机群（3 架弹幕机绕 Boss 飞行）| 优先清理护卫机或极限走位 |
| 40%（转阶段）| Boss 核心暴露（红色发光点），全屏弹幕密度降低 | 集中火力攻击核心（2 倍伤害）|
| 40%~20% | 进入过载：弹幕速度 +30%，但 Boss 停止移动 | 利用固定靶优势猛攻 |
| 20%（转阶段）| Boss 开始缓慢下压（降低玩家活动空间）| 必须快速输出，否则被压死 |
| 20%~0% | 绝望模式：全屏随机落弹 + 横向扫射激光 | 极限生存测试 |

**通用转阶段反馈**：
- Boss 血量到达阶段阈值时，**时间缩放降至 0.3**（持续 0.5s）
- Boss 颜色闪烁（白→红→白）3 次
- 屏幕震动 + 警报音效变调

### 3.6 单局成长：通关奖励选择

**现状**：通关后直接结算，缺少策略选择。

**改进：三选一奖励系统**

每关击败 Boss 后，弹出奖励选择面板：

```
┌─────────────────────────────────┐
│      任务完成 - 选择补给          │
├─────────────────────────────────┤
│  [A] 装甲修复      [B] 炸弹补给   │
│  恢复 3 HP          获得 1 炸弹   │
│                                 │
│  [C] 武器预热                    │
│  下关初始火力 +1                  │
└─────────────────────────────────┘
```

**设计意图**：
- 低 HP 时选 A，缺炸弹时选 B，想速通时选 C
- 简单难度可三选二，困难难度只能三选一

## 四、性能与架构改进

### 4.1 对象池系统（高优先级）

**现状分析**：
- `PlayerController.FireOffsetShot`：每发子弹 `new GameObject()`
- `BlockSpawner.SpawnEnemy`：每个敌机 `new GameObject()`
- `EffectsController.EmitParticles`：每个粒子 `new GameObject()`
- Burst 阶段同屏可能有 50+ 子弹 + 20+ 敌机 + 100+ 粒子，GC 压力巨大

**实现方案**：

```csharp
// 建议新增：Assets/Scripts/Runtime/ObjectPool.cs
public class ObjectPool<T> where T : Component
{
    private Queue<T> pool = new Queue<T>();
    private T prefab;
    private Transform parent;
    
    public T Get()
    {
        if (pool.Count > 0)
        {
            T obj = pool.Dequeue();
            obj.gameObject.SetActive(true);
            return obj;
        }
        return Object.Instantiate(prefab, parent);
    }
    
    public void Return(T obj)
    {
        obj.gameObject.SetActive(false);
        pool.Enqueue(obj);
    }
}
```

**需要池化的对象**：
1. 玩家子弹（4 种武器 × 各等级弹幕数）
2. 敌机（普通/强化/精英）
3. 敌弹（普通/Boss 弹）
4. 金币
5. 爆炸粒子
6. 碎片
7. 飘字（Score Popup / Powerup Label）

### 4.2 材质与着色器升级

| 效果 | 当前实现 | 升级方案 |
|------|----------|----------|
| 子弹发光 | 纯色 Sprite | 使用 **Additive 材质**，让重叠区域更亮 |
| 爆炸核心 | 纯色 Sprite | 使用 **Additive + 颜色叠加**，模拟光晕 |
| 战机轮廓 | 无 | 添加 **Outline Shader**（选中/无敌时高亮边框）|
| 能量护盾 | 无 | 使用 **半透明 Fresnel 材质**，边缘发光 |
| 屏幕后处理 | 无 | 可选 **CRT 扫描线** + **暗角（Vignette）** |

### 4.3 音效多样化

**现状**：所有音效都是程序化生成（`BuildPulseTone`、`BuildNoiseBurst` 等），虽然巧妙但重复度高。

**改进方向**：
- 保留程序化音效作为**后备方案**
- 为不同武器添加**差异化射击音效**：
  - 扇形弹：短促 "哒哒"（现有）
  - 激光："嗡——" 的持续音 + 发射尾音
  - 追踪弹："嘀嘀" 的电子锁定音
  - 爆裂：低沉的 "嗵" + 爆炸回响
- Boss 警报添加**心跳节奏**（随 Boss 血量降低，心跳加快）
- 添加**环境音层**：引擎轰鸣、风声、远处爆炸（低音量背景层）
